# V28 — JLCPCB-style Color Palette

Based on the supplied JLCPCB reference screenshot.

## Palette
- PCB / solder mask green: `#17642F`
- Copper / exposed copper gold: `#C6A03C`
- Silkscreen / outline: `#FFFFFF`
- Drill: `#111111`
- Viewer background: `#E7E9EC`
- UI changed to a light neutral style to match the reference presentation.

## Important
This version changes **colors only**. V27 geometry, G74 handling, board bounds, macro handling, drill registration, and layer classification are preserved.
